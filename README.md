# 💣 Destructive Button

Приложение-прикол про кнопку **«Очистить экран»**, которая делает ровно наоборот: вместо чистоты экран заполняется случайными эмодзи и иконками, которые жёстко накладываются друг на друга. Чем больше нажимаешь — тем быстрее и обильнее спавн, пока всё не начнёт лагать и в итоге не упадёт.

Сделано намеренно сломанным. Это фича, а не баг

## Что происходит

| Нажатие | Интервал между порциями | Эмодзи за раз |
|--------:|-------------------------|---------------|
| старт   | 5.0 с                   | 1             |
| 1       | 3.0 с                   | 1             |
| 2       | 1.8 с                   | 4–6           |
| 3       | 1.08 с                  | 7–11          |
| 4       | 0.65 с                  | 12–18         |
| 5       | 0.39 с                  | 19–27         |
| …       | до 40 мс                | до 150        |

- **Интервал** режется на 40% за каждое нажатие (минимум 40 мс).
- **Размер пачки** одновременно растёт на 2–4 эмодзи (максимум 150 за раз).
- Лимита на общее количество мусора **нет** — список растёт бесконечно, и приложение рано или поздно падает.
- Фон постепенно краснеет, а подпись кнопки и текст над ней деградируют по стадиям.

## Запуск

```bash
flutter pub get
flutter run
```

Требуется установленный Flutter SDK.

## Сборка

```bash
flutter build apk      # Android
flutter build ios      # iOS (нужен macOS)
flutter build web      # Web
```

## Архитектура

`main.dart` только запускает приложение, вся логика и UI разнесены по слоям.

```
lib/
├── main.dart                          # точка входа: preload шрифта → runApp
├── app.dart                           # MaterialApp: тема и стартовый экран
├── core/
│   └── font_loader.dart               # предзагрузка Material Icons
├── data/
│   └── chaos_content.dart             # эмодзи, иконки, тексты
├── models/
│   └── blob.dart                      # модель одного «мусорного» элемента
├── controllers/
│   └── chaos_controller.dart          # вся логика: таймер, эскалация, спавн
└── screens/ + widgets/
    ├── screens/chaos_screen.dart      # экран, собирает всё вместе
    └── widgets/
        ├── chaos_garbage_layer.dart   # слой мусора
        ├── blob_view.dart             # один элемент с анимацией появления
        ├── chaos_hud.dart             # верхняя панель со счётчиками
        ├── stat_item.dart             # мини-счётчик для HUD
        └── chaos_controls.dart        # сообщение + большая кнопка
```

## Иконки

Иконки приложения генерируются пакетом [`flutter_launcher_icons`](https://pub.dev/packages/flutter_launcher_icons):

```bash
dart run flutter_launcher_icons
```

Настройки — в `pubspec.yaml` (секция `flutter_launcher_icons`), исходники — в `assets/icon/`.

Источник иконки: эмодзи 💣 из [Openmoji](https://openmoji.org/) — лицензия [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
